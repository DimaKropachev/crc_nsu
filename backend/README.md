# Бэкенд VK Mini App: карьерные консультации НГУ

Go-модульный монолит для записи студентов на карьерные консультации. HTTP API имеет префикс `/api/v1` и согласован с фронтенд-контрактом, приведённым в промпте.

## Состояние реализации

В проекте реализованы:

- Проверка подписи параметров запуска VK Mini Apps HMAC-SHA256 и выдача JWT access token.
- Автоматическое создание пользователя по VK ID. Роль `admin` выдаётся только VK ID из `ADMIN_VK_IDS`; пользователь не может задать роль в HTTP-запросе.
- PostgreSQL-схема с миграциями, уникальностью VK ID, ограничениями ролей, историей записей и защитой от пересекающихся слотов консультанта.
- Список консультантов и свободных слотов, управление слотами консультанта.
- Запись, просмотр, перенос один раз и отмена консультации. Критичные операции записи выполняются в транзакциях с блокировками PostgreSQL.
- Подтверждение и завершение консультаций, история изменений.
- Приватное хранение файлов PDF/DOCX, проверка прав доступа, ограничение размера.
- Асинхронный worker AI-анализа PDF/DOCX с OpenAI-compatible API; перед созданием задания сервер требует `external_ai_consent: true` и фиксирует отметку согласия и время в записи анализа. Задания без согласия worker не обрабатывает. При пустом `AI_PROVIDER` основной сервис работает, а endpoint анализа возвращает `503`.
- Отдельный worker напоминаний за 24 часа через VK Messages API. Отправка выключена по умолчанию и работает только после явной записи согласия пользователя через `POST /api/v1/me/notification-consent`.
- Health endpoints, единый формат ошибок, ограничение частоты запросов на авторизацию/загрузку, Dockerfile, Compose и OpenAPI.

## Требования

- Go 1.23+ для запуска без Docker.
- Docker Compose v2 и Docker Engine для контейнерного запуска.
- PostgreSQL 16 (Compose поднимает базу сам).
- Для авторизации нужны `VK_APP_ID` и `VK_APP_SECRET` из настроек VK Mini App.
- Для назначения консультантов укажи VK ID через `ADMIN_VK_IDS`.
 
## Запуск через Docker Compose

Все команды этого раздела выполняются из корня репозитория. Используется единый compose для frontend и backend.

1. Скопируй корневой файл окружения:

   ```bash
   cp .env.example .env
   ```

2. Отредактируй `.env`: задай уникальный `POSTGRES_PASSWORD`, `VK_APP_ID`, `VK_APP_SECRET`, `ADMIN_VK_IDS` и случайный `JWT_SECRET` длиной не менее 32 символов. Не используй секреты из примера в production.

3. Запусти сервис:

   ```bash
   docker compose up --build
   ```

   Compose поднимет PostgreSQL, применит миграции и затем запустит API и frontend. Приложение и API доступны через nginx по `http://localhost:8080`, если `HTTP_PORT` не переопределён. Порт Go API наружу не публикуется.

4. Проверь работоспособность:

   ```bash
   curl http://localhost:8080/api/v1/health/live
   curl http://localhost:8080/api/v1/health/ready
   ```

## Запуск без Docker

Нужна локальная PostgreSQL и установленный бинарник `migrate` из golang-migrate.

```bash
cp .env.example .env
# Укажи DATABASE_URL для своей локальной PostgreSQL и загрузите переменные окружения.
set -a
. ./.env
set +a
go mod download
migrate -path migrations -database "$DATABASE_URL" up
go run ./cmd/api
```

Команды разработчика:

```bash
make fmt
make test
make vet
make build
make migrate-up
make migrate-down
```

Интеграционный тест жизненного цикла консультаций и конкурентного бронирования пропускается, если не задан `TEST_DATABASE_URL`. Запускай его только против отдельной тестовой PostgreSQL-базы: тест создаёт и удаляет временную схему.

```bash
export TEST_DATABASE_URL='postgres://app:password@localhost:5432/career_consultations_test?sslmode=disable'
go test ./tests -run TestPostgresConsultationLifecycle -v
```

`migrate-down` удаляет объекты последней миграции. Не запускай его на базе с данными, которые нужно сохранить.

## Авторизация VK Mini Apps

Фронтенд отправляет исходные параметры из `window.location.search` в `POST /api/v1/auth/vk`:

```json
{ "launch_params": "vk_app_id=...&vk_user_id=...&sign=..." }
```

Сервер проверяет подпись параметров, извлекает подтверждённый VK ID, создаёт или обновляет пользователя и возвращает Bearer token. Все остальные защищённые маршруты используют заголовок `Authorization: Bearer <access_token>`.

**Важно:** проверяйте интеграцию на реальных параметрах запуска и настройках своего VK Mini App до публикации. Параметры с `sign` должны передаваться без преобразования фронтендом. Сервер не принимает роль от клиента.

### Первый администратор

Добавь VK ID консультантов в `ADMIN_VK_IDS`, разделяя запятыми. При входе такого пользователя будет создан `consultant_profile`. В текущей модели роль `admin` имеет права консультанта. Снятие роли — отдельная административная операция в БД; удаление VK ID из `.env` само по себе не понижает уже созданную роль.

## API и формат ошибок

Полная схема находится в `api/openapi.yaml`. Основные группы:

- `/auth/vk`, `/me` — авторизация и профиль.
- `/consultants`, `/consultations` — пользовательские сценарии.
- `/admin/slots`, `/admin/consultations`, `/admin/profile` — инструменты консультанта.
- `/files/resumes`, `/files/{id}` — резюме.
- `/resume-analyses` — создание и получение AI-анализа.
- `/health/live`, `/health/ready` — проверки здоровья.

Ошибки возвращаются в формате:

```json
{
  "error": {
    "code": "SLOT_UNAVAILABLE",
    "message": "Выбранное время уже недоступно",
    "details": {}
  }
}
```

Все временные метки API передаются в ISO 8601 / RFC3339. Запросы диапазонов слотов используют `from` и `to` в формате RFC3339.

## Настройка AI

Для включения AI-анализа задай `AI_PROVIDER=openai` или `AI_PROVIDER=openai-compatible`, `AI_API_KEY` и `AI_MODEL`. При необходимости измени `AI_BASE_URL`. Worker опрашивает очередь в PostgreSQL и извлекает текст из PDF/DOCX.

Показывай в интерфейсе согласие на обработку резюме внешним AI-провайдером до вызова `POST /api/v1/resume-analyses`. Отправляй вместе с `file_id` поле `external_ai_consent: true`; сервер проверяет его и сохраняет флаг с временной меткой в записи анализа. Задания без явного согласия не ставятся в очередь. Не передавай в анализ файлы без действия пользователя. Сканированные PDF без извлекаемого текстового слоя завершатся ошибкой: OCR в этом MVP не включён.

## Напоминания VK

Напоминания отключены по умолчанию. Чтобы включить их, настрой:

```dotenv
REMINDER_ENABLED=true
NOTIFICATION_PROVIDER=vk
NOTIFICATION_API_TOKEN=<community-token>
VK_API_VERSION=5.199
```

Затем приложение должно запрашивать явное согласие у пользователя и отправлять `POST /api/v1/me/notification-consent` с `{"enabled": true}`. Согласие можно отозвать, передав `false`. Для отправки со стороны сообщества VK может требовать доступность диалога с пользователем и соответствующие разрешения. Факт успешной доставки подтверждается ответом VK API; при ошибках worker повторяет отправку ограниченное число раз.

Указанная версия VK API задана конфигурацией и должна проверяться при обновлении интеграции. В production держи токен сообщества только в серверных переменных окружения.

## Безопасность и эксплуатация

- Реальный `.env` не добавляется в git.
- Файлы хранятся в директории вне публичного веб-корня с правами доступа `0600`.
- В PostgreSQL используется `TIMESTAMPTZ`, а временные метки API нормализуются в UTC для запросов.
- Необходимо настроить HTTPS на ingress/reverse proxy в production.
- Настрой `CORS_ALLOWED_ORIGINS` списком точных origin фронтенда.
- Пример `DATABASE_URL` в Compose использует `sslmode=disable` только для внутренней локальной сети контейнеров. Для внешней production-БД включи TLS, например `sslmode=require`.
- Устанавливай лимиты хранения и срок удаления резюме согласно правилам обработки персональных данных организации.
- Требуется настроить бэкапы PostgreSQL и persistent volume с файлами; сами файлы и записи в БД необходимо резервировать согласованно.

## Известные ограничения MVP

- Модули волонтёрства, мероприятий, стажировок, стипендий и рассылок пока не реализованы — они оставлены вне текущего объёма API.
- Нет административного веб-интерфейса для назначения ролей: первичный список администраторов задаётся через `ADMIN_VK_IDS`.
- Извлечение текста работает для PDF с текстовым слоем и DOCX; OCR, антивирусная проверка, S3-совместимое хранилище и полноценное управление политиками хранения не реализованы.
- Напоминания не отправляются без явного согласия пользователя и настроенного токена сообщества VK.
- Integration-тесты против реального PostgreSQL и сквозная проверка VK/AI API должны запускаться в среде с доступными Docker/network/секретами. В текущем контейнерном окружении сеть для скачивания Go-модулей недоступна.
